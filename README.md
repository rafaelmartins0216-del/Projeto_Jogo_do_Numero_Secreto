# 🎯 Projeto Jogo do Número Secreto

Projeto simples desenvolvido para **estudos de lógica de programação**, utilizando **HTML, CSS e JavaScript**.

O jogo consiste em adivinhar um número secreto gerado aleatoriamente pelo sistema, recebendo dicas até acertar.

---

## 🧠 Objetivo do Projeto

- Praticar lógica de programação  
- Trabalhar com manipulação do DOM  
- Utilizar JavaScript para interatividade  
- Integrar HTML, CSS e JS em um projeto simples  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** – estrutura da página  
- **CSS3** – estilização  
- **JavaScript** – lógica do jogo
